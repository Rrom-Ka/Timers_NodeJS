# ⏱️ Веб-приложение для отслеживания времени (Тайм-трекер)

Простое и быстрое веб-приложение для тайм-трекинга. Позволяет создавать именованные таймеры, наблюдать за их ходом в реальном времени и сохранять историю завершенных сессий в базу данных.

В этом репозитории представлены две разные версии приложения:

### 🚀 [Timers NoAuth](./timers-noauth) — Базовая версия

- **Фронтенд:** Чистый Vanilla JS (SPA).
- **Связь:** Обычные AJAX-запросы. Текущий прогресс тикающих таймеров рассчитывается локально в браузере клиента, не нагружая сеть.
- **Доступ:** Без авторизации. Все таймеры общие.

### 🔒 [Timers Real-time](./timers-realtime) — Продвинутая версия

- **Фронтенд:** Vue.js v2 + UIkit 3.
- **Связь:** Синхронизация через **WebSockets**. Сервер каждую секунду сам транслирует точный прогресс задач всем клиентам.
- **Доступ:** Полноценная авторизация (сессии на куках `httpOnly`, хеширование паролей по SHA-256). Данные изолированы под каждого пользователя.
