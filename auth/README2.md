# Timers App ⏱️ — Веб-приложение для трекинга времени

Современное веб-приложение для управления таймерами в реальном времени. Проект разработан с использованием гибридной архитектуры, совмещающей классический REST API для управления сущностями и протокол WebSocket для мгновенной синхронизации прогресса задач без лишних AJAX-запросов.

## 🚀 Особенности проекта

- **Авторизация**: Полноценная регистрация и вход пользователей с безопасными сессиями на базе кук (`httpOnly`).
- **Синхронизация по WS**: Автоматическая отправка актуальных списков и прогресса активных таймеров каждую секунду всем подключенным клиентам.
- **Отказоустойчивость**: Бэкенд оптимизирован под рекурсивный `setTimeout` для защиты пула соединений MongoDB и предотвращения "наползающих" асинхронных запросов.
- **Безопасность данных**: Криптографическое хеширование паролей (`SHA-256` + соль) и строгая изоляция данных — пользователи имеют доступ только к своим таймерам.
- **Интерфейс**: Реактивное управление состоянием списков (активные и завершенные таймеры) на фронтенде с помощью Vue.js.

## 🛠 Технологический стек

- **Backend**: Node.js, Express.js
- **Database**: [MongoDB Драйвер v3.6](https://mongodb.com) (с оптимизированным пулом `poolSize: 10`)
- **Real-time**: [ws](https://github.com) (WebSocket-сервер с автоматической очисткой ресурсов на разрывах)
- **Шаблонизация**: [Nunjucks](https://github.io) (изолированные теги для бесконфликтной интеграции с фронтендом)
- **Frontend**: [Vue.js v2](https://vuejs.org) (реактивный UI), [UIkit v3.5.4](https://getuikit.com) (стили и пуш-уведомления)

## 📦 Установка и запуск

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com
   cd timers-app
   ```

2. **Установите зависимости:**

   ```bash
   npm install
   ```

3. **Настройте конфигурацию (файл `.env`):**

   ```env
   PORT=3000
   DB_URI=mongodb://localhost:27017
   PASSWORD_SALT=ваш_секретный_криптографический_ключ
   NODE_ENV=development
   ```

4. **Запустите проект:**
   - В режиме разработки (с автоматическим перезапуском):
     ```bash
     npm run dev
     ```
   - В режиме продакшена:
     ```bash
     npm start
     ```
